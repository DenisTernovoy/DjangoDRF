# Проект DjangoRF

## Описание:

Проект DjangoRF - это проект по созданию backend-части веб-приложения с использованием фреймворков Django и Django Rest Framework.

## Установка:

1. Клонируйте репозиторий:

    ```
    git clone https://github.com/DenisTernovoy/DjangoDRF.git
    ```

2. Выберите *Poetry* в качестве интерпретатора.

### Запуск проекта

1. Установите Docker, если он ещё не установлен.
2. В терминале перейдите в директорию проекта.
3. Запустите команду: `docker-compose up`

### Проверка работоспособности

1. **Бэкенд**: Откройте браузер и перейдите по адресу `http://localhost:8000`.
2. **PostgreSQL**: Используйте команду `psql -h localhost -U <username> -d <database>` для подключения. Выполните простую команду, например, `SELECT 1` и проверьте, что она выполняется успешно.
3. **Redis**: Выполните команду `redis-cli -h localhost ping`. Убедитесь, что ответ "PONG".
4. **Celery** и **Celery Beat**: Проверьте логи в терминале, чтобы убедиться, что задачи выполняются без ошибок.
